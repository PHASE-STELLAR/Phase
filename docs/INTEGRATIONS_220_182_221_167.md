# Gated integration slice — phase-220 / 182 / 221 / 167

One branch, four independently reversible integrations. Every surface is
gated by an env flag (default off); unsetting a flag restores the previous
behavior with no migration and no data rewrite.

| Flag | Feature | Flag off behavior | Rollback |
|------|---------|-------------------|----------|
| `phase-220` | Stellar Expert deep links + read-only enrichment | Raw transaction hashes only | Unset env; `/api/explorer/enrichment` returns 404 |
| `phase-182` | Classic pools + Soroswap router adapter | `/api/liquidity-pools` returns 404; intents inert | Unset env; sidecars stay on disk but are never read |
| `phase-221` | Albedo sunset / retirement | Legacy guarded Albedo paths, banner hidden | Unset env; guards pass through |
| `phase-167` | WalletConnect session resilience | Default wallet-kit behavior | Unset env; session metadata ignored |

## phase-220 — Explorer (Spike 648)

- `lib/explorer-links.ts`: `buildExplorerUrl` produces testnet Stellar Expert
  links and fences mainnet behind `PHASE_EXPLORER_ALLOW_MAINNET=1`.
  `isSafeExplorerUrl` is an allow-list (https + `stellar.expert` + known path).
- `sanitizeEnrichmentRequest` accepts only `kind` and `id` — a wallet address,
  email, memo or any other field is rejected before a request is made.
- `fetchTxEnrichment` / `fetchAssetEnrichment` use Horizon with a 3 s abort
  timeout and return `{ ok:false, reason }` instead of throwing.
- `components/explorer-enrichment-panel.tsx` always shows the raw hash; with
  the flag off it shows **only** the hash. With the flag on it adds the link and
  metadata, and falls back to a localized "metadata unavailable" line.
- Endpoint: `GET /api/explorer/enrichment?kind=tx&id=<64-hex>`.

## phase-182 — Pools (Spike 574)

- Uses the upstream `lib/liquidity-pool.ts` (SQLite `pool_activity` table) with
  `liquidity-pool-intents.json` for quote-hash idempotency; the merge keeps the
  upstream store rather than downgrading it to a parallel JSON store.
- Constant-product quotes include fee, min-out, short TTL and a deterministic
  SHA-256 quote hash. `assertQuoteUsable` rejects stale/mismatched quotes as
  `QUOTE_STALE` / `QUOTE_MISMATCH` (409).
- Deposit / withdraw / pool-share trustline builders return **unsigned** XDR;
  the existing `signTransaction` path keeps signing client-side.
- Soroswap has **no default router**. `SOROSWAP_ROUTER_CONTRACT_ID` is required
  and `SOROSWAP_EXPECTED_ROUTER_ID` drift fails closed (503) before a tx is built.
- `recordPoolIntent` is idempotent by `wallet:intentId`: identical retries replay,
  different payloads return `INTENT_CONFLICT` (409).
- `spendableAfterPoolSeed` subtracts seed capital, fee reserve and pending holds.
  `screenPoolActivity` / `getPoolVolumeExcludingWash` flag self-provision and
  self-swap activity and exclude it from volume.
- Endpoint: `GET/POST /api/liquidity-pools`. Live proof harness:
  `npx tsx scripts/phase-182-pool-proof.ts` (writes real tx hashes to
  `.data/phase-182-pool-proof.json`; refuses to fabricate them).

## phase-221 — Albedo sunset (Spike 626)

- `lib/albedo-sunset.ts` registers all six Albedo call sites and resolves
  `parity-freeze` (default) or `retired` from `ALBEDO_SUNSET_MODE`.
- Every call site is gated: the intent bundle is never imported after
  retirement; `signTransaction` fails closed with migration copy; the legacy
  implicit-tx banner is suppressed.
- `@albedo-link/intent` stays pinned at 0.12.0; new call sites are rejected
  while the program is active.
- Endpoint: `GET /api/albedo/status` (mode, pin check, call-site registry).
- This branch uses `phase-221` instead of the spike draft's `phase-170`, which
  is already assigned to the log pipeline.

## phase-167 — WalletConnect (Spike 623)

- `lib/walletconnect-resilience.ts`: relay candidate resolution + failover,
  chain-switch guard, localStorage session persistence, deep-link return
  restricted to same-origin relative paths, bounded reconnect backoff.
- `restoreWcSession` validates a persisted session before it is trusted and
  records the closed `session_restored` counter only on success.
- Banner: `components/walletconnect-banner.tsx` (flag-gated, localized copy).
