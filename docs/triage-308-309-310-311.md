# Triage: issues #308, #309, #310, #311

## Summary

Reviewed four filed issues against the actual code in the files they cite. In each case the
described behavior does not exist in that file. Findings were posted as comments on the
respective issues; this note collects them in one place for reference.

## #311 — `lib/market-store.ts`: amount string vs number lexicographic comparison

Cited range `:42-118` reviewed in full. `amount_phaselq`/`price_phaselq` are declared `REAL` in
the SQLite schema (`lib/sqlite-db.ts`). Every SQL ordering is `ORDER BY amount_phaselq DESC`
(numeric on a `REAL` column), and every JS-side comparison is either arithmetic
(`b.price_phaselq - a.price_phaselq`, which coerces both operands numerically regardless of
type) or guarded by `Number.isFinite(...)` before use. No bare `<`/`>`/`.sort()` is applied to
raw string values anywhere in this file.

## #309 — `lib/toast-queue.ts`: cold-start loss on Vercel

Cited range `:12-34` reviewed. `ToastQueue` is a `"use client"` browser-side class, instantiated
via the `useToastQueue` hook and consumed only in client components. It never runs inside a
Vercel serverless function, so "resets on cold start" does not apply — that failure mode is
specific to server-side function instances, not a per-tab in-memory object in the browser.

## #310 — `lib/phaser-liq-sac-warn.ts`: clawback griefing via SAC warn bypass

Cited range `:12-34` reviewed. This module validates that a configured token contract ID is a
well-formed Contract ID and, if valid, compares it against the expected SAC address —
logging `console.error`/`console.warn` on mismatch. It never reads or sets trustline flags,
`AUTH_CLAWBACK_ENABLED`, or touches any settlement/payment path. No side effects beyond
`console` output.

## #308 — `lib/og-design-tokens.ts`: cache poisoning leaking a private OG image

Cited range `:12-34` reviewed. This file only defines static, public design-token constants and
zod schemas (colors, dimensions) for the OG image renderers. There is no caching logic in the
file — no `Cache-Control` handling, no cache keys, no storage — and nothing in it is private;
every value here is presentational and already visible in the rendered OG images.

## Common thread

All four issue bodies share an identical Description/Why/Task template (Yjs CRDT +
`Y.Doc`/`WebsocketProvider`, a Postgres `signals` table migration, "50-concurrent-edit" tests)
regardless of title — that block is unrelated to any of the four files above. Only the titles
and the cited `file:line` ranges differ between issues, and the ranges themselves don't contain
the claimed behavior either.

## Recommendation

Close #308–#311 as not reproducible, per the comments already posted on each. Reopen
individually with concrete repro steps if any was meant to describe a real, different issue.
